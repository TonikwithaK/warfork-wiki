Maps are places where the game takes action. Maps consist of brushes (floor, walls) and entities (objects that have a purpose like doors). Players can load a map by typing *map \<mapname\>* into the [[console]].
Maps are named using the following template: *\<game\> \<gametype\> \<id\>*. For example, wfca1 stands for Warfork Clan Arena 1.
