Race is a special game type with a goal to complete a course with the fastest time possible using various <a href="movement" class="wikilink" title="movement">movement</a> abilities, unlike eliminating enemies in any other game type.

Players can only race on race maps. Players cannot hurt each other and aren't solid and players cannot take damage.

- Players cannot die. *kill* command results in player respawning.
